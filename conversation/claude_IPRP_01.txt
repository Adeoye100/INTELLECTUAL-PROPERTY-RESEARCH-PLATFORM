Good catch on where to look — the CSS is fighting itself. Two concrete bugs, plus one structural mismatch:

    body { color: var(--bg); } — that's backwards. It sets default text color to the background teal instead of the text color. Almost certainly a copy-paste slip.
    --text-h (headings) is #08060d — near-black, left over from the original light-theme template. Your headline text is rendering white via a Tailwind class elsewhere in the component, which overrides this — but nothing in this file ever gives the page an actual dark background to sit on.
    --bg is only a flat teal, never the navy→teal gradient your brand actually calls for, so wherever that flat teal isn't painted, you get white-on-white.
    The @media (prefers-color-scheme: dark) block defines a third, unrelated gray theme that can kick in depending on a visitor's OS setting — Forge Global's palette is a fixed brand, not something that should flip based on system preference. That block is part of why colors look inconsistent depending on where you check.
